# CaseCellShop-BackEnd
Um pequeno serviço backend para a CaseCellShop que exponha catálogo de produtos com cache, inicie um checkout assíncrono e permita consultar o status do pedido. Use dados em memória ou serviços locais/simulados se preferir. O objetivo é demonstrar raciocínio pleno de backend, cache, observabilidade e consistência.
